# Размер существа, масштаб и масса

Источник: [Creature Size](https://the-official-worldbox-wiki.fandom.com/wiki/Creature_Size); редакция `22312`, дата `2026-05-22T00:50:16Z`. План подготовлен по полному тексту этой редакции.

## Что подтверждает источник

Статья разделяет четыре вещи: неизменяемый класс размера 0–17, геометрический size, визуальный scale и массу. Хищник по естественной диете выбирает добычу не крупнее своего класса; класс 0 не выполняет выделение отходов. Самый крупный класс усиливает некоторые посмертные выбросы. Визуальное увеличение чертой не обязано менять класс добычи. Масса участвует в физике и количестве ресурсов, но в исходнике несколько разных mass-полей.

Оговорки: Некоторые обозначения mass в источнике различаются по контексту. В плане нужны собственные однозначные имена вместо буквального копирования двух неодинаковых масс.

## Наша отправная точка

В `src/core/types.ts` есть радиус solid, скорость/импульс motion и параметры визуальных сущностей. `src/render/residents.ts` использует возрастной размер, а `src/content/kaiju.ts` — отдельную крупную модель. Общей биологической шкалы размеров и массы пока нет.

## Взаимодействия и результат

- Волк выбирает пищу → сравнивает классы размера и съедобность → крупная недопустимая цель не становится добычей.
- Черта увеличивает масштаб → меняются визуальная модель и вычисляемая масса → базовый видовой класс сохраняется.
- Удар сообщает импульс → масса ограничивает перемещение → существо не проваливается сквозь препятствие.
- Гибель кислотного существа → класс размера определяет выпуск → эффект ограничен бюджетом событий.

Ниже описывается предлагаемая реализация Pocket World. Числа из исходной статьи служат отдельным ориентиром, а переносимые ограничения проверяются на масштабе нашего мира. Не объявлять одинаковыми понятия только из-за похожего имени: принадлежность, выполняемое действие и временное состояние должны сохранять собственный смысл.

## Приёмка

- Увеличенный визуально кролик не меняет пищевой класс без отдельного правила.
- Волк не охотится на класс 14.
- Несъедобная фея не становится добычей из-за малого класса.
- Тяжёлый объект получает меньший сдвиг от одинакового импульса.
- Масштаб после загрузки не умножается повторно.
- Сохранение в середине активного перехода и продолжение после загрузки дают тот же результат и расход случайности, что непрерывная симуляция; пауза не двигает таймеры.
- Удаление участника, владельца или цели не оставляет ошибочных ссылок; недоступность пути не считается успешным действием. Если механика не требует перемещения, проверять доступность объекта через его жизненный цикл.

Проверить актуальные валидаторы `src/content/components.ts` и `src/persistence/schema.ts`, добавить миграцию только при необходимости формата. Выполнить относящиеся модульные проверки и реальную проверку отображаемого результата, затем сборку.
