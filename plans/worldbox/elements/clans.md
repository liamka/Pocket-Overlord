# Кланы, родовые права и наследование

Источник: [Clans](https://the-official-worldbox-wiki.fandom.com/wiki/Clans); редакция `23157`, дата `2026-10-13T01:12:26Z`. План подготовлен по полному тексту этой редакции.

## Что подтверждает источник

Клан — родовая организация, способная пересекать границы государств. Он имеет главу, черты, лимит членов и доступ к замыслам. Королевским для государства считается клан правителя. Дети правителей могут вступать при рождении; основатель подтягивает детей без клана, клон наследует клан. При двух родительских кланах статус короля приоритетнее лидера. Преемство зависит от культуры: возраст, дипломатия, война, слава, деньги и пол. Blood Pact изгоняет враждебного главе члена, Deathbound убивает его.

Оговорки: Правила распада королевства принадлежат Rebellions; здесь только сигнал отсутствия наследника. Названия/девизы генерировать собственные.

## Наша отправная точка

Родители/партнёры уже есть в `src/core/types.ts`, старейшины — в `src/systems/governance.ts`; ни Clan, ни королевского родства нет. Семейная группа миграции не подходит в качестве клана: она должна путешествовать вместе, тогда как клан может охватывать несколько держав.

## Взаимодействия и результат

- Король основывает клан → дети без клана присоединяются в пределах лимита → появляется royalClanId.
- Наследник рождается от двух правителей → выбирается допустимый род по приоритету → ребёнок остаётся в своей семейной структуре.
- Глава погибает → культура выбирает преемника → связи с королевствами пересчитываются.
- Член стал подданным врага главы → соответствующее решение запускает изгнание/казнь → обычный клан без этих черт ничего не делает.

Ниже описывается предлагаемая реализация Pocket Overlord. Числа из исходной статьи служат отдельным ориентиром, а переносимые ограничения проверяются на масштабе нашего мира. Не объявлять одинаковыми понятия только из-за похожего имени: принадлежность, выполняемое действие и временное состояние должны сохранять собственный смысл.

## Работы

1. Ввести Clan с главой, основателем, культурой главы, членами, чертами, лимитом, историей и отметкой редактирования.
2. Оформить вступление при рождении/клонировании/основании отдельными событиями; запретить произвольное присоединение взрослого по близости.
3. Реализовать выбор главы и общую кандидатуру для государственных должностей; учитывать отсутствие кандидата без рекурсивного бесконечного поиска.
4. Разделить резервный Attribute Dice и обычное наследование: избранность увеличивает число бросков только в указанном случае, RNG сохраняется.
5. Проверять изменившуюся войну непосредственно перед наказанием; не уничтожать ставшего мирным родственника по устаревшему решению.
6. Добавить карточку родства, должностей, претензий и причин исключения.

На каждом переходе обновлять данные владельца и связанные ссылки вместе; промежуточное состояние не должно давать повторную награду или оставлять участника одновременно в несовместимых состояниях. Для игрока показать действующую причину, участника и наблюдаемое следствие, а не служебный идентификатор. Обновлять текст через `src/i18n.ts`; существующие действия жителей и доступные команды должны продолжать работать.

## Приёмка

- Членство семьи не означает членство клана.
- Клан может иметь членов двух государств.
- Лимит не удаляет существующих членов молча.
- Гибель главы запускает один выбор.
- Мир до завершения наказания отменяет недействующую цель.
- Сохранение в середине активного перехода и продолжение после загрузки дают тот же результат и расход случайности, что непрерывная симуляция; пауза не двигает таймеры.
- Удаление участника, владельца или цели не оставляет ошибочных ссылок; недоступность пути не считается успешным действием. Если механика не требует перемещения, проверять доступность объекта через его жизненный цикл.

Проверить актуальные валидаторы `src/content/components.ts` и `src/persistence/schema.ts`, добавить миграцию только при необходимости формата. Выполнить относящиеся модульные проверки и реальную проверку отображаемого результата, затем сборку.
